# My Task Manager

A simple, beautiful task manager built with HTML, CSS, and JavaScript.

## Features
- Add and delete tasks
- Mark tasks as complete
- Track completion progress
- Clean, modern design

## How to Run
1. Open `index.html` in your web browser
2. Start adding tasks!
